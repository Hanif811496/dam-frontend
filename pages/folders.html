Smart Folder
Kelola Smart Folder sebagai struktur bertingkat seperti Explorer. Folder Divisi menjadi root, Smart Folder dapat memiliki subfolder, dan Rules Auto-Assign diatur langsung dari folder yang sedang dipilih.
Folder
Pilih folder di sebelah kiri untuk melihat isi dan pengaturannya.
Buat Smart Folder
Pilih lokasi. Jika dibuat di dalam Smart Folder, akses divisi otomatis mengikuti parent.
Akses divisi mengikuti lokasi yang dipilih.
Pindahkan Smart Folder
Folder tidak dapat dipindahkan ke dirinya sendiri atau ke salah satu subfoldernya.
Bagikan Smart Folder
Anggota divisi tujuan akan melihat folder ini pada bagian Dibagikan ke Saya beserta nama pemberi share.
